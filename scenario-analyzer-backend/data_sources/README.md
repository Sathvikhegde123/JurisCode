# Scenario Analyzer Data Sources

This folder stores official/statutory source PDFs used to verify and expand the source packs.

Current MVP does not parse these PDFs.

Current MVP does not perform full RAG.

Current MVP uses curated JSON source packs stored in `/source_packs`.

Expected PDFs to add manually later:

1. Transfer_of_Property_Act_1882/

   - For lease, transfer of property, sale deed, possession, and landlord-tenant context.

2. Registration_Act_1908/

   - For registration of documents, sale deeds, gift deeds, partition deeds, and document-related disputes.

3. RERA_Act_2016/

   - For builder delay, delayed possession, allottee rights, and RERA complaint context.

4. Hindu_Succession_Act_1956/

   - For inheritance, legal heirs, ancestral/self-acquired property disputes among Hindus.

5. Indian_Succession_Act_1925/

   - For will/testamentary succession contexts where applicable.

6. Specific_Relief_Act_1963/

   - For injunction, specific performance, cancellation, and civil relief-related context.

Important:

- Exact section-level verification is pending.

- Do not claim exact source sections are verified unless confirmed manually.

- Full RAG over these PDFs is a future enhancement.

- Current system uses curated official statutory summaries from source packs.
