# Jupyter Notebooks

This directory contains research, experimentation, and training notebooks used in the development of JurisCode Bharat.

## Key Notebooks

- `qwen25_premise_generator_lora_training.ipynb`: Notebook for fine-tuning the Qwen 2.5 model with the Premise Generator LoRA.
- `current_model_training_file_opposing_counselling.ipynb`: Training pipeline for the Opposing Counsel model.
- `indian-courtroom-judge-vanilla.ipynb`: Exploration of judge-like behavior and response generation.

## Purpose

These notebooks document the model training process, hyperparameter choices, and initial evaluation of model performance before deployment to the backend.
