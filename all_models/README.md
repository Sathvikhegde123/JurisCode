# All Models

This directory serves as a comprehensive repository for all LoRA adapters and model variants developed for JurisCode Bharat, including various versions and experimental outputs.

## Subdirectories

- `objection_model/`: LoRA adapter for legal objection evaluation.
- `opposing_counsel/`: Various versions of the opposing counsel simulator.
- `premise_model/`: Multiple versions of the premise generator.
- `benchmark_outputs/`: Evaluation results and performance metrics for the models.

## Usage

While production models are typically moved to the root `models/` folder, this directory remains the primary workspace for model development and benchmarking.
